# ForgeOS 1.1.2 — 커밋 기록

`1.1.1` 과 달리 이 릴리즈는 **커밋 플랜이 아니라 커밋 기록**입니다. 부팅 2단계 교체가
`v1.1.1` 태그를 단 뒤에 이어서 커밋되었기 때문에, 앞으로 할 일이 아니라 이미 한 일을
적어 둡니다.

## 들어간 커밋

| 커밋 | 내용 |
|---|---|
| `1834cfe` | `FirefoxApp.java` 삭제 — `1.1.1` 의 ForgeWeb 개명에서 남아 있던 파일 |
| `0bf978b` | 소스 덤프 최신화 |
| `dacf29f` | **부팅 2단계를 MP4에서 로고 스플래시로** — `BootSplash` 신규, `BootVideo` 삭제, `BootSequence` 교체, `javafx.media` 제거, `theme.css` 의 `.boot-video` → `.boot-splash` 계열 10개 규칙, README 두 벌 |
| (이 커밋) | 버전 `1.1.2`, 릴리즈 문서, 그리고 `1.1.1` 문서 원복 |

## 마지막 커밋이 `1.1.1` 문서를 되돌리는 이유

`dacf29f` 가 스플래시를 넣으면서 `docs/RELEASE_NOTES_1.1.1.md` 와
`docs/COMMIT_PLAN_1.1.1.md` 까지 스플래시 내용으로 고쳤습니다. 그런데 `v1.1.1` 은
그보다 **세 커밋 앞**에서 태그가 붙었고, 거기에는 스플래시가 없습니다 —
`1.1.1` 이 실제로 한 일은 영상을 앞 3.6초만 쓰도록 자른 것이었습니다.

이미 배포된 릴리즈의 문서가 그 릴리즈에 없는 기능을 설명하고 있으면 안 되므로,
두 문서를 `v1.1.1` 태그 시점 내용으로 되돌렸습니다. 스플래시 이야기는
[1.1.2 릴리즈 노트](RELEASE_NOTES_1.1.2.md)가 맡습니다.

## 버전

`version` 만 `1.1.2` 로 올리고 **`forgeFrameworkVersion` · `forgeCliVersion` 은
`1.1.1` 그대로** 둡니다. 커널과 CLI는 이 릴리즈에서 바뀐 것이 없습니다.
`1.1.0` 부터 지켜 온 "세 저장소 번호 맞추기"가 여기서 처음 어긋납니다.

## 태그와 배포

```bash
./gradlew clean build
./gradlew run                       # 눈으로 확인 — 아래 목록

git tag -a v1.1.2 -m "ForgeOS 1.1.2 — MP4를 걷어내고 로고 스플래시로"
git push origin HEAD
git push origin v1.1.2
```

커널·CLI는 `1.1.1` 그대로이므로 다시 배포하지 않습니다.

## 확인 목록

컴파일과 CSS 는 자동으로 확인됩니다. **아래 넷은 사람이 봐야 합니다.**

- [ ] 스피너가 **시계 방향**으로 도는지 (`Arc` 는 양수가 반시계, `Node.setRotate` 는 양수가 시계 — 부호가 반대입니다)
- [ ] 콘솔이 흐려지는 자리에서 로고가 떠오르는지 — 검은 화면만 보이는 구간이 없어야 합니다
- [ ] 마지막에 호가 완전한 원으로 닫히고 나서 데스크탑이 뜨는지
- [ ] 후광 점선이 큰 창에서 너무 튀지 않는지, 최소 창(960×640)에서 잘리지 않는지

그 밖에:

- [ ] `./gradlew build` — `-Xlint:all -Werror` 경고 0건
- [ ] 부팅 전체가 4초대인지 (`ESC` · `Space` · 클릭으로 건너뛰는 것도 그대로인지)
- [ ] 배포본 크기가 줄었는지 — `javafx.media` 네이티브가 빠집니다
